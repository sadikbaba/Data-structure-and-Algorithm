# Phase 3: Two Pointers

## Goal

Learn when two pointers can remove unnecessary repeated work compared with a brute-force nested-loop solution.

## Concepts

- Left and right pointers
- Fast and slow pointers
- Sorted-array problems
- Removing duplicates
- Reversing
- Partitioning
- Palindrome checking
- Why two pointers can reduce the right problem from O(n²) to O(n)

## Prerequisite

Phase 2: Arrays and Strings

## Problems

- [ ] Remove duplicates from a sorted array in place
- [ ] Find a pair in a sorted array that sums to a target
- [ ] Reverse a string using two pointers

## Skills to Gain

By the end of this phase, I should be able to:

- Recognize when two pointers fit a problem
- Choose where each pointer should start
- Decide how each pointer should move
- Explain why two pointers are better than a nested-loop brute-force solution when applicable
- Analyze time and space complexity

## What Not to Study Yet

Do not mix two pointers with sliding window yet.

Sliding window is a separate pattern and comes in Phase 4.

## Exit Criteria

Given a new sorted-array problem:

1. Decide whether two pointers apply.
2. Explain why.
3. Implement the solution without reference.
4. Complete it in under 10 minutes.
5. State the time and space complexity.
